# WORKFLOW v0.7 对齐修订建议

## Workflow 不是固定 SOP

Numi Workflow 中的阶段代表：

> 协作状态。

不是：

> 强制执行流程。

------------------------------------------------------------------------

# 协作流程

    Project Understanding

    ↓

    Feature Definition

    ↓

    Work Unit Design

    ↓

    Delivery State

    ↓

    Acceptance

------------------------------------------------------------------------

# 自适应原则

协作方式根据：

-   Agent 能力；
-   Harness 能力；
-   用户经验；
-   项目成熟度；
-   风险等级；

动态调整。

------------------------------------------------------------------------

# 人工关注点

人工主要负责：

-   目标；
-   判断；
-   取舍；
-   风险。

Agent 主要负责：

-   分析；
-   实现；
-   验证；
-   执行。
