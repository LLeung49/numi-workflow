# Workflow Capability Matrix v0.7 Final

## Capability Ownership Model

所有能力统一分为三类：

  类型        定义
  ----------- ------------------
  Own         numi 核心能力
  Reuse       复用成熟外部能力
  Reference   仅描述，不实现

------------------------------------------------------------------------

# Numi Own

## Project Authority

包括：

-   项目基线；
-   长期项目依据；
-   架构约束；
-   领域上下文。

------------------------------------------------------------------------

## Feature Definition

包括：

-   目标；
-   范围；
-   决策边界；
-   验收标准。

------------------------------------------------------------------------

## Feature Delivery State

包括：

-   当前状态；
-   完成证据；
-   验收情况；
-   升级条件。

------------------------------------------------------------------------

# Reuse

复用：

-   TDD；
-   Code Review；
-   Worktree；
-   Debugging；
-   Implementation Workflow。

来源：

-   Superpowers；
-   Matt Pocock Skills；
-   Coding Agent。

------------------------------------------------------------------------

# Reference

仅描述：

-   Model Provider；
-   Agent Harness；
-   Execution Backend。

numi 不负责：

-   选择模型；
-   调度 Agent；
-   管理执行环境。
