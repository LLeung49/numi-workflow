# Feature Deliver MVP Scope v0.7

## 目标

建立最小 Feature 交付闭环。

核心：

> 让人和 Agent 围绕同一个 Feature 状态可靠协作。

------------------------------------------------------------------------

# Included

## 1. Feature State Tracking

记录：

-   Feature 当前状态；
-   Ticket 状态；
-   阻塞原因；
-   验证状态。

------------------------------------------------------------------------

## 2. Evidence Collection

记录：

-   测试；
-   代码；
-   Review；
-   文档；
-   运行结果。

------------------------------------------------------------------------

## 3. Delivery Boundary

定义：

-   什么情况下继续执行；
-   什么情况下需要人工决策；
-   什么情况下回退 feature-shape。

------------------------------------------------------------------------

## 4. Handoff Contract

定义 Agent/session 切换时需要保持的信息。

不实现具体 handoff 工具。

------------------------------------------------------------------------

# Excluded

## 不做 Agent Runtime

不负责：

-   调度 Agent；
-   管理 Agent 生命周期。

------------------------------------------------------------------------

## 不做 Workflow Engine

不强制：

-   固定步骤；
-   固定执行顺序。

------------------------------------------------------------------------

## 不做 Capability Marketplace

Capability Catalog 仅用于描述和复用。

------------------------------------------------------------------------

# 验收标准

Feature Deliver MVP 完成后：

用户可以回答：

1.  当前 Feature 到哪里了？
2.  下一步是什么？
3.  为什么认为已经完成？
4.  如果换 Agent，如何继续？
5.  哪些问题需要人工判断？
