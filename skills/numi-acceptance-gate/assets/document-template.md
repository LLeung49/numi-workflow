# 验收方案与测试报告模板 (Document Templates)

> **使用指引：**
> - **如果当前处于编码前（切片设计、方案制定）**：使用 **【模板 A：验收方案与判定单】**，所有执行状态一律保持 `⚪ NOT_RUN`，严禁预设通过结果。
> - **如果当前处于编码后（代码已提交、执行验收）**：使用 **【模板 B：实测验收报告】**，必须填入真实运行命令、退出码与终端日志证据。
